Student Gradebook Management System

About the Project

The Student Gradebook Management System is a C# application developed to help manage student academic records and marks.

Technologies Used

- C#
- .NET Windows Forms
- Visual Studio

Key Features

- User login system
- Role-based access
- Student marks management
- Capturing and viewing academic results
- Grade calculation
